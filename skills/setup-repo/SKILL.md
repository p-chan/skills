# GitHub リポジトリの設定

GitHub に作成した直後のリポジトリに使う。設定が初期値のままである前提で、既存の設定との競合は扱わない。

完了条件をすでに満たしている手順はスキップする。

## 1. マージ方式を決める

許可するマージ方式（squash / merge commit / rebase）をユーザーに確認する。

## 2. リポジトリを設定する

次の設定になっていること。

- 手順 1 で決めたマージ方式だけが許可されている
- マージ後のブランチ自動削除が有効

## 3. デフォルトブランチのルールセットを作る

デフォルトブランチ（`~DEFAULT_BRANCH`）を対象とする、次のルールを持つルールセットが有効であること。

- 削除の禁止（`deletion`）
- force push の禁止（`non_fast_forward`）
- PR 必須、承認数 0（`pull_request`）。`allowed_merge_methods` は手順 1 で決めたマージ方式に揃える

GitHub Free の private リポジトリはルールセットに対応していないので、この手順はスキップする。それ以外の理由で作成に失敗した場合は、スキップせず未完了として報告する。

## 完了報告

変更した内容と、スキップした手順・未完了の手順とその理由をユーザーに報告する。
