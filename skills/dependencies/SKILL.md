# 依存の追加と更新

次の状態にする。

- 互換性やクールダウンなどの制約を満たす、最新の安定版を使っている
- バージョンがファイルで固定されている

## 追加コマンドがある依存

`package.json` などのマニフェストファイルや `pnpm-lock.yaml` などのロックファイルは直接編集せず、パッケージマネージャーのコマンドで追加・更新する（例: `pnpm add <pkg>`）。直接編集すると記憶にある古いバージョンが入りやすいが、コマンドならその時点の最新版が解決される。

バージョンは、互換性などの理由があるときだけ指定する。

リリース後の待機期間（クールダウン）が設定されているときは、その期間を満たす最新版を使う。期間内のバージョンが必要なときは、設定を変更したり除外に足したりせず、ユーザーに確認する。

## 追加コマンドがない依存

Gradle、GitHub Actions、Dockerfile のベースイメージなどは、レジストリなどの情報源で最新の安定版を確認してから、ファイルに書く。
